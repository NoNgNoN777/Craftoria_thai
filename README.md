# Craftoria ภาษาไทย

ชุดภาษาไทยสำหรับ **Craftoria 1.37.0** บน Minecraft Java **1.21.1 · NeoForge** อ่านเควส คำอธิบายไอเทม และคู่มือในม็อดเป็นไทย โดยยังค้นชื่อไอเทม บล็อก และม็อบด้วยชื่ออังกฤษใน EMI/JEI ได้

> สถานะ: แปลครบตามขอบเขตแล้ว และผ่านตัวตรวจอัตโนมัติ **ยังไม่ได้ทดสอบในเกม** ถ้าเจอปัญหา แจ้งได้ที่ Issues

## วิธีติดตั้ง

1. ปิดเกม แล้วเปิดโฟลเดอร์ instance ของ Craftoria (โฟลเดอร์ที่มี `mods` และ `config`) สำรอง `config/ftbquests` ไว้ก่อน
2. แตก `Craftoria_Thai_for_players.zip` แล้วคัดลอก **ทั้ง `config` และ `resourcepacks`** ไปวางทับใน instance
3. เปิดเกม เลือก **Options → Language → English (US)** จากนั้นไปที่ **Resource Packs** เปิด `ZZ_Craftoria_Thai.zip` ไว้บนสุด
4. ฟอนต์ไทย: แนะนำให้ลงแพ็กฟอนต์ไทย (เช่น ThaiFontFix) แล้วเปิดไว้ใต้ชุดภาษาไทย ฟอนต์ของเกมแสดงสระและวรรณยุกต์ไม่สวย

ย้อนกลับ: ปิดเกม คัดลอกทุกอย่างในโฟลเดอร์ `ย้อนกลับ_ไฟล์อังกฤษเดิม` (ไฟล์เควสภาษาอังกฤษของแพ็ก) ไปวางทับใน instance ลบ `config/ftbquests/quests/lang/th_th.snbt` แล้วปิด `ZZ_Craftoria_Thai.zip` ในหน้า Resource Packs หรือคืน `config/ftbquests` ที่สำรองไว้

## ข้างในมีอะไร

| ส่วนของเกม | จำนวน |
| --- | --- |
| ข้อความในม็อด (tooltip คำอธิบาย ข้อความแจ้งเตือน หนังสือในตัวม็อด) | 29,472 ข้อ |
| สมุดเควส FTB Quests | 2,148 ระเบียน (ไม่นับเควสที่ถูกลบออกจากแพ็กแล้ว 1,652 ระเบียน) |
| หนังสือ Patchouli | 4,817 ข้อความ |

ตั้งใจคงอังกฤษ: ชื่อไอเทม บล็อก ม็อบ ม็อด advancements หน้าตั้งค่า ปุ่มลัด และคำสั่งของแอดมิน ส่วนชื่อเควสเป็นแบบ "ไทย (English)"

ยังไม่ได้แปล: คู่มือ AE2 (ไฟล์ Markdown ในม็อด), หน้าเมนู FancyMenu และข้อความในสคริปต์ KubeJS ของแพ็กเอง

## หมายเหตุสำหรับเควส

แพ็กนี้มีม็อด FTB Quests Lang Splitter ซึ่งรวมไฟล์ภาษาที่แยกเป็นรายบทใน `config/ftbquests/quests/lang/en_us/` กลับเข้าไฟล์หลักตอนโหลด ชุดนี้จึงแปลไฟล์แยกบททั้ง 65 ไฟล์ด้วย ถ้าเปิดเควสแล้วบางบทยังเป็นอังกฤษ ให้แจ้งพร้อมชื่อบท

### ฟอนต์หนังสือ Patchouli

รวมตัวแก้ฟอนต์หนังสือที่ทดสอบกับ Oathbound Codex แล้ว โดยต้องเปิด **TLB Itim Font V 1.2** ใต้ **ZZ_Craftoria_Thai.zip** ตัวแก้อ้างไฟล์ minecraft:itim.ttf จากแพ็ก Itim ผู้ทดสอบยืนยันว่าเข้าเกมและอ่านภาษาไทยในหนังสือได้ หนังสือเล่มอื่นและการเปิดเกมซ้ำยังต้องตรวจเพิ่ม
